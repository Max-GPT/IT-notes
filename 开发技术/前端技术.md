# Next.js
#### Next.js = React 企业级开发框架。
React 本身只负责：页面(UI)
```
React
    ↓
负责写页面
```

Next.js 解决：
```
Next.js
    ↓
React + 路由 + SSR + 打包 + 部署
```

React 是基础，Next.js 是框架。Next.js 运行在 Node.js 上。就像：
```
JavaScript 世界

React
↓
Next.js
↓
Node.js
```

```
Java 世界

Java
↓
Spring Boot
↓
JVM
```

# Node.js（简称 Node）
JavaScript 的运行环境（Runtime），让 JavaScript 可以脱离浏览器运行。

### 为什么会有 Node.js？
- 最开始，JavaScript 只能在浏览器 Chrome / Edge / Safari 里运行。
- 如果要 写服务器程序 / 操作文件 / 启动 Web 服务 / 开发工具
- 怎么办？浏览器做不了这些事情。
- 于是 2009 年诞生了 Node.js。它让 JavaScript 能像 Java、Python 一样，在操作系统上直接运行。

#### Node.js = JavaScript 的 JVM（帮助理解的类比）。
